# Portofolio Rusi Adristi

Website Portofolio Pribadi Interaktif dan Profesional yang menampilkan profil keahlian, pengalaman kerja, sertifikasi, serta galeri proyek di bidang Teknologi Informasi (Web Developer & IT Support) dan Manajemen Administrasi Perkantoran.

## Live Demo

Akses website portofolio secara langsung melalui GitHub Pages:

```text
https://rusiadristi.github.io/portofolio_rusiadristi/
```

## Requirement

Pastikan sudah terinstall:

* Git
* Web Browser modern (Google Chrome, Microsoft Edge, Mozilla Firefox)
* Code Editor (VS Code, Sublime Text, atau Notepad++) jika ingin mengembangkan kode

Cek Git:

```bash
git --version
```

## Instalasi

Clone repository:

```bash
git clone https://github.com/rusiadristi/portofolio_rusiadristi.git
cd portofolio_rusiadristi
```

## Menjalankan Website

1. Buka folder hasil clone atau unduhan.
2. Klik ganda file `index.html` untuk langsung membukanya di web browser, atau jalankan melalui live server / web server lokal (seperti XAMPP atau VS Code Live Server):

```text
http://localhost/portofolio_rusiadristi/
```

## Struktur Halaman & Fitur Utama

* **Portal Utama (`index.html`):** Halaman pembuka interaktif dengan konsep dual-track showcase yang memberikan pilihan penelusuran portofolio sesuai kebutuhan audiens (jalur IT atau Administrasi).
* **Portofolio Teknologi Informasi (`it.html`):**
  * Ringkasan profil profesional dan filosofi kerja di bidang IT.
  * Tech Stack & Keahlian Teknis: PHP, Laravel, JavaScript, MySQL, HTML5, CSS3, Tailwind CSS, Bootstrap, Git, dan IT Support.
  * Showcase Proyek: Menampilkan portofolio aplikasi web lengkap dengan tangkapan layar, teknologi yang digunakan, serta deskripsi fungsional.
  * Akses Dokumen: Tautan langsung untuk melihat dan mengunduh Curriculum Vitae (CV) digital.
* **Portofolio Administrasi Perkantoran (`administrasi.html`):**
  * Kompetensi kearsipan digital, korespondensi resmi, dan manajemen administrasi perkantoran.
  * Penguasaan perangkat lunak perkantoran (Microsoft Word, Excel, PowerPoint, Google Workspace).
  * Dokumentasi sertifikasi keahlian dan riwayat pelatihan profesional.
* **Desain Responsif & Interaktif:** Dibangun dengan tata letak adaptif yang nyaman diakses pada perangkat smartphone, tablet, maupun layar desktop resolusi tinggi.
* **Aset Dokumen Resmi (`pdf/`):** Terintegrasi dengan dokumen CV dan portofolio resmi berformat PDF yang dapat langsung diakses publik.
